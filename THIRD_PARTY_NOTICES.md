# Third-party components

verbit (formerly 片言 and 听记/Tingji) uses the components below. This project's own source is MIT. Each dependency keeps its own license; MIT does not relicense those components. Runtime packages and weights are not committed to this repository.

## Current desktop installer

Default recording-only and optional native API flows require Windows and .NET Framework 4.8, not Python or model weights. The application's third-party binaries are NAudio and the two native LAME libraries below. Windows/.NET system components are prerequisites, not redistributed runtime bundles. Inno Setup's generated installer/uninstaller components are covered separately below.

- [NAudio 1.10.0](https://www.nuget.org/packages/NAudio/1.10.0): **Microsoft Public License (Ms-PL)**, copyright Mark Heath & Contributors (the NuGet package identifies © Mark Heath 2020). The exact tagged [upstream license](https://github.com/naudio/NAudio/blob/v1.10.0/license.txt) is included in [packaging/licenses/NAudio.txt](packaging/licenses/NAudio.txt). Distributions containing `NAudio.dll` must preserve its notices and license. NAudio changed to MIT in version 2.0; the current upstream branch's license is not the license of 1.10.0.
- LAME 3.100 native encoder: GNU Library GPL v2, with later-version permissions where specified by upstream files. Dynamically loaded from the pinned NAudio.Lame 1.1.1 NuGet package; the managed wrapper is not included. The Windows installer includes both DLLs (about 1.70 MiB combined), the full 3.100 upstream source archive (about 1.45 MiB), [license](packaging/licenses/LAME.txt) and [source/replacement details](packaging/licenses/LAME-SOURCE.md). No Python or FFmpeg is required for new recordings' initial MP3 export. Restore/build checks fixed hashes; compatible LGPL library replacements remain possible at runtime.

## Distribution requirements and build tool

The lightweight desktop distribution must include this notice, the project's `LICENSE`, the NAudio license when it includes `NAudio.dll`, and the LAME license, source/replacement instructions and corresponding source archive when it includes the native MP3 encoder libraries. It does not include Python packages, FFmpeg or model weights. Installing those from their official providers does not convert their licenses to MIT. A new all-in-one/offline distribution must inventory every included package, native library and model and provide the required licenses, notices and corresponding source arrangements before publication.

The Windows setup program is built with [Inno Setup](https://jrsoftware.org/isinfo.php). Its compiler is a separately downloaded build tool, not part of the application payload. Inno Setup retains its own [license](https://jrsoftware.org/files/is/license.txt), including the notices and addresses present in its generated setup/uninstaller components.

## Artwork and synthetic test material

The user-approved logo is the text-free folded-paper and waveform symbol in `assets/verbit-logo.png`, generated for this project with the built-in image tool using a user-supplied visual reference; its exact model version was not exposed. The reference image itself is not distributed in this repository. The project name `verbit` is rendered separately from the symbol. `assets/Create-Icons.ps1` packages the PNG into the current ICO resources and adds the recording-state indicator. The blue/red waveform SVG files are legacy artwork, not the source of the current icons. See [brand and asset notes](documentation/brand.md) for the approved design and small-size rules.

The GitHub mark in assets/github-mark.png is GitHub's official mark, obtained from https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png and used only to identify the project link. GitHub marks remain GitHub trademarks and are not relicensed under this project's MIT license. See https://github.com/logos for the applicable brand guidance.

`assets/engine-check.wav` is synthetic Mandarin generated for this project's offline smoke test with Windows System.Speech / Microsoft Huihui Desktop; see `assets/engine-check-source.md` for the exact generic text and format. It contains no user recording. The voice engine and voice model are not distributed with verbit. This sample checks that inference runs and is not a meeting-quality benchmark.
