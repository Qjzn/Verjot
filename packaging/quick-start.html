verbit

随手记一句，轻松留下会议记录。

先设置，再开始

首次打开时，选择录音和笔记的保存目录，确认快捷键后点击「保存并启动」。之后程序驻留托盘，右键菜单中的「设置…」可以再次修改。

速记可以直接用

按 Ctrl + Alt + J 打开置顶便签。支持输入文字、粘贴图片和自动保存；收起后重新打开可继续写，不需要 Python、模型或 Obsidian。

先录音，转写时再准备模型

没有 Python 或模型也能先录音。结束后若提示「录音已保存 · 待配置转写」，无损录音保存在程序目录 work 下。准备好模型并保存设置后，从「最近会议」选择对应场次「重试这场转写」。此时才生成最终 MP3 和 Markdown；等待期间不要删除恢复资料。

安装时可勾选下载推荐的千问中文转写，或稍后从“设置 → 转写 → 下载推荐模型…”准备。无需预装系统 Python，所需依赖与说话人组件一起安装；下载需数 GB 空间，音频留本机。安装包本身不含模型，速记可直接使用。详见程序目录的 本地完整安装说明。

Ctrl + Alt + L 开始 / 结束会议
默认不足 5 秒的误触录音不保存、不转写。
Alt + Space 暂停 / 继续麦克风
按一次暂停麦克风，再按一次恢复；与浮窗麦克风按钮共用状态，电脑声音持续录制。
Ctrl + Alt + K 标记重点时间
会后从 Markdown 中查看对应时间点。

你的文件由你保管

会议完成后只保留一条 MP3 和一份 Markdown。API 模式会将音频发送到你配置的服务；本地模式在本机处理。升级和卸载前，请从托盘正常退出。卸载保留配置、运行环境和已有记录。
