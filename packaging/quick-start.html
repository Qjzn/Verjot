verbit

随手记一句，轻松留下会议记录。

先设置，再开始

首次打开时，选择录音和笔记的保存目录，确认快捷键后点击「保存并启动」。之后程序驻留托盘，右键菜单中的「设置…」可以再次修改。

速记可以直接用

按 Ctrl + Alt + J 打开置顶便签。支持输入文字、粘贴图片和自动保存；收起后重新打开可继续写，不需要 Python、模型或 Obsidian。

默认仅录音，按需配置第三方转写

按 Ctrl+Alt+L 开始或结束，先生成并校验一条 MP3。新会议以 verbit 加年月日时分建目录；同分钟重录自动加序号，不覆盖旧文件。需要文字时再配置 API，成功后同目录生成同名 Markdown；失败先检查具体原因，不要删除恢复资料。

默认仅录音，速记与录音无需 Python、模型或开发环境；首期不提供推荐模型下载。需要转写时，可在“设置 → 转写”选配第三方音频转写 API，提交前确认上传。已有模型和配置保留。新文件以 verbit 加年月日时分命名，同分钟自动加序号。详见 安装与 API 配置说明。

Ctrl + Alt + L 开始 / 结束会议
默认不足 5 秒的误触录音不保存、不转写。
Alt + Space 暂停 / 继续麦克风
按一次暂停麦克风，再按一次恢复；与浮窗麦克风按钮共用状态，电脑声音持续录制。
Ctrl + Alt + K 标记重点时间
会后从 Markdown 中查看对应时间点。

你的文件由你保管

会议完成后只保留一条 MP3 和一份 Markdown。API 模式会将音频发送到你配置的服务；本地模式在本机处理。升级和卸载前，请从托盘正常退出。卸载保留配置、运行环境和已有记录。
