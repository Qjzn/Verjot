verbit 0.1.0-beta.1

适用系统：Windows 10 1809 / Windows 11 x64，.NET Framework 4.8。

这是当前用户安装包，不需要管理员权限。默认安装到：
%LOCALAPPDATA%\Programs\verbit

安装后首次打开将弹出设置窗口。保存目录和四组快捷键确认后，
可以直接使用 Ctrl+Alt+J 打开置顶速记，输入文字、粘贴图片并自动保存。

会议录音与转写需要另外安装 Python 3.12 x64 和相应运行环境。
可以使用 OpenAI 兼容的语音转写 API，或单独下载本地中文模型。
安装包不下载模型，不上传音频，不包含 API 密钥或个人数据。

首次设置会提供安装说明入口。完整步骤见：
documentation\install-windows.md

升级或卸载前，请从托盘正常退出 verbit，避免中断正在进行的记录。
卸载只移除安装包中的程序文件和快捷方式，保留个人配置、模型、
虚拟环境、工作资料和已经保存的录音、笔记。

本测试版尚未配置代码签名。下载后请核对 GitHub Release 的 SHA256。
