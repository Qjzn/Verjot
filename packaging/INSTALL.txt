verbit · Windows x64

需要 Windows 10 1809+ / Windows 11 x64 和 .NET Framework 4.8。
速记、录音和新 API 转写无需 Python、模型或开发环境。
安装器与设置不提供推荐模型下载，不后台下载模型。

首次设置选择保存目录和快捷键，默认仅录音：
Ctrl+Alt+J 速记；Ctrl+Alt+L 开始/结束；Alt+Space 只暂停麦克风。
新会议：保存目录/verbit/verbit年月日时分/，MP3 和转写 Markdown 同名。
同分钟重录自动加序号，不覆盖旧文件。自定义会议子目录保留。

需要转写时在设置中选配第三方 /audio/transcriptions 地址、模型 ID
和密钥变量名；Key 在本机用户环境变量填写。提交前确认音频上传。
仅录音不上传。已有模型、Python、配置和录音保留，不自动切换。

完整说明：documentation/install-windows.md
升级前从托盘正常退出。卸载保留个人资料与后装环境。
此候选未签名，仓库保持私有；核对随包 SHA256 后安装。
