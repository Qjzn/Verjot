# 后台任务

没有按时间自动开启会议或定时上传任务。除用户显式开启的版本检查外，后台工作由当前用户操作触发：

| 任务 | 触发、范围与限制 | 恢复/停止 |
| --- | --- | --- |
| 速记保存 | 编辑停顿后，在本机后台依次保存草稿、正文与图片；只处理当前便签。 | 收起/退出等待保存；冲突或失败保留内容，不覆盖外部版本。 |
| 会后导出/转写 | 结束有效录音后由原生进程导出并校验 MP3；默认仅录音，启用 API 且确认后才提交音频。 | 失败保留恢复资料；最近会议可重试并复用完整检查点，不覆盖修改后的笔记。 |
| 启动恢复 | 扫描本机工作目录并核对已有 worker 身份、当前尝试与状态。 | 只附着仍运行的任务，不在启动时自动重跑或上传旧会议。 |
| 版本检查 | `check_updates` 默认关闭；显式开启后启动时及每 24 小时只读 GitHub 发布信息。 | 网络错误不打断会议；下载/安装仍由用户在更新窗口触发，不上传音频或笔记。 |

状态来自会话的 `session.json`、`status.json`、`controller.json` 和进程身份；API 密钥只在 API worker 中从环境读取。桌面托盘/浮窗展示实际阶段，不能把动画当作处理百分比或质量证明。
