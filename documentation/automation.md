# AI 处理边界

verbit 使用语音模型完成转录和说话人分组，没有可自行调用工具的 Agent，也不会因会议中的一句指令执行命令、发消息或发布内容。

| 阶段 | 允许输入/接口 | 输出与约束 |
| --- | --- | --- |
| 本地语音处理 | 当前会话无损片段、本地安装的模型、用户填写的识别上下文。 | 文本、时间戳和匿名身份分组；本地加载不信任远端模型代码。 |
| API 转写 | 仅 API 模式；用户配置的兼容 `/audio/transcriptions`，凭据来自指定环境变量。 | 校验服务响应，错误不回显完整响应正文；拒绝重定向转发。 |
| 成品写入 | worker 控制文件名、路径、检查点、正文和音频发布。 | 模型文本没有文件系统或系统工具权限；失败保留可重试资料，不自动公开结果。 |

`asr_context` 是识别提示，不是权限规则。硬性边界由代码执行：URL 校验、超时/大小限制、路径校验、状态检查和用户触发。API 转写可能上传音频并产生费用；本地处理不等于准确率已获验收，归属与重叠内容仍按 [质量说明](quality.md) 核对。
