# 权限范围

> beta.11 首期调整：新用户默认仅录音，无推荐本地模型下载；速记、原生 MP3 导出与可选第三方 API 均无需 Python 或模型。新 API 提交完整 MP3，身份信息仅来自供应方；已有 local 模式及下文历史 Python 流程保留兼容，不属于新用户推荐路径。新会议按 `verbit年月日时分/同名.mp3` 保存，API 成功后生成同名 Markdown。实际配置见[安装说明](install-windows.md)。


安装器使用 `PrivilegesRequired=lowest`，默认当前用户安装。程序不绕过 Windows 文件权限，不自带多用户或角色授权。

| 资源 | 当前用户授权的操作 | 界限 |
| --- | --- | --- |
| 麦克风/播放设备 | 用户开始会议后采集；快捷键、浮窗或菜单仅暂停/继续麦克风，电脑声音持续录制；结束才停止整场。 | 不修改会议软件的通话静音；受保护/独占音频可能无法采集。 |
| 保存目录与应用工作目录 | 保存笔记、图片、录音、配置和恢复状态。 | 路径校验、重名与外部修改保护；更新地址不迁移旧内容。 |
| 系统剪贴板 | 只在用户主动粘贴时读取；主动复制/剪切时写入。 | 没有后台监视、自动清空或测试时备份恢复。 |
| HKCU、当前用户快捷方式 | 安装器登记卸载；可选登录启动；用户另行启用回放协议。 | 不覆盖其他安装目录拥有的协议；卸载保留用户资料。 |
| API 服务商 | 仅在确认后提交本场完整 MP3，使用用户环境变量密钥；旧 Python 兼容链仍提交片段。 | 无内置账户/密钥；服务商的访问、费用和保留政策由用户管理。 |

共享 Windows 账户能访问该账户可读的配置和会议内容；本工具不提供文件加密或账户间隔离。更详细的副作用见 [流程](flows.md)，报告漏洞见 [SECURITY.md](../SECURITY.md)。
