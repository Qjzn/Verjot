## 本轮补齐的验收入口

- [集中设备复验](device-revalidation.md)：准备阶段不打开音频，开始前倒计时，提前结束保存，逐包时钟与人工反馈分开。
- 干净安装的合成录音现在显式使用新版原生导出入口，再运行真实本地转写并核对 MP3 哈希；避免旧版合成清单静默走历史导出路径。
- 新沙箱完成初始空白环境核验、首次设置及速记的 32 条实际窗口断言。旧标题选择器已先复现再修正；模型依赖下载与 CPU 推理仍需完整客体结果。
- 宿主实际安装载荷与现有本地模型的合成处理通过：两路 8 段、21.886 秒，正文 CER 为 0，位置误差检查通过，MP3 哈希一致且临时原段清理。这是已知固定样本，不外推为真实会议准确率或干净安装通过。
- 相关 Python 回归 99 项，1 项跳过；其余通过。准备窗口和未开始/取消路径另有 14 条断言，分析器单独 4 项检查包含在上述 Python 计数中，不重复累加。
- 验收脚本、逐包分析和研究依赖不加入基础安装包；安装包仅增加本报告及相关使用说明。

当前交付判断：可以保留本地候选和完整证据；真实设备关键项未通过时，不同步为“验收通过”的私有候选，不公开发布。音频内容与人物资料仅留本机，仓库只保存匿名结论。
