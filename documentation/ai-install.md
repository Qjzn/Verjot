# 交给 AI 安装

将以下内容交给安装助手：

> 安装 Verjot 0.1.0-beta.38，按 documentation/install-windows.md 使用官方仓库的 Windows x64 EXE 和同版本 SHA256。确认 .NET Framework 4.8、可写保存目录与系统兼容性，默认仅录音。不安装 Python、模型、CUDA 或 FFmpeg，不自动连接旧模型。首次确认保存目录和快捷键，先验证速记可用。保留已有配置、模型、笔记、录音与 work 恢复资料；不要强杀程序，不操作用户剪贴板。实际录音、播放或 API 上传须先取得明确同意。分别报告通过、失败、跳过和未测，不用自检或合成测试代替真实设备结果。

## API 可选配置

用户主动要求时收集 API 服务前缀、音频转写模型 ID、密钥环境变量名。Key 由用户在本机 Windows 用户变量填写，不放进聊天、命令参数、配置文件或日志。只支持兼容 multipart `/audio/transcriptions` 的 MP3 转写服务；普通聊天模型不能代替。

设置检查与保存不上传；提交音频前必须由用户确认服务地址与模型。失败保留资料，不自动换供应方、不自动循环重试，不覆盖已有 Markdown。

## 验证与更新

先核对版本、安装器 SHA256、开始菜单与首次设置，再在独立文件夹检查便签输入、收起与重开。图片粘贴由用户主动完成，不代读或改写系统剪贴板。真实录音需用户配合确认麦克风与电脑声，输出实际文件位置。

更新使用程序正常保存与退出，检查没有进行中的录音／转写后再安装到原目录。安全检查拒绝时调查原因，不绕过。私有仓库需对应访问权限，窗口更新不能匿名获取时改用登录后的手动下载。
