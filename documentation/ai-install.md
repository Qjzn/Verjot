# AI 协助安装与排障

## 首期开源路径

先确认 Windows 10 1809+ / Windows 11 x64、.NET Framework 4.8、可写保存目录和音频设备。使用与说明匹配的 beta.11 EXE，核对 SHA256。**不要为首期安装 Python、千问、说话人模型、FFmpeg 或 CUDA。** 安装器和设置页不提供推荐模型下载。

首次设置只确认保存目录与快捷键，默认仅录音。速记先于任何转写配置可用。记录安装版本、文件哈希、退出码及未验证项；不能把构建或依赖检查当成真实录音通过。详见[安装步骤](install-windows.md)。

## 可选第三方 API

只有用户主动要求时才在设置中勾选“录音 + 转写”。收集服务前缀、音频转写模型完整 ID、密钥环境变量名、超时；Key 由用户在本机 Windows 用户环境变量填写，不进入配置、命令参数、聊天或日志。API 必须兼容 multipart `/audio/transcriptions`，支持上传 MP3 与 `response_format=json`。模型 ID 可自定义，普通聊天模型不能代替转写接口。

新 API 流程不使用 Python 或本地说话人分组。提交前明确显示音频去向并征得确认；录音完全本地时不调用 API。未配置转写不妨碍录音。整条 MP3 单次提交，服务上限和身份识别能力需单独核对，不能宣称所有第三方可用。不要为绕过服务限制把用户音频上传到其他地址。

超时、断网、HTTP 错误、空结果或时间轴不合法时保留原文件与恢复资料。不要自动循环重试：供应方可能已收到且计费。不要覆盖原笔记或删除 work 来掩盖失败。

## 已有用户和实验环境

升级保留 `config.json`、`.venv/`、`models/`、录音和速记；不改已有目录、快捷键或转写模式，不强制关闭正在运行的程序。已有 local 配置仍使用原来的无损分轨工作流；没有本地环境的新用户不展示无效的本地选择。单独修改模型名不会更换本地架构。

源码保留 `Install.ps1`、`download_models.py`、`RecommendedModel.ps1` 等历史/研究工具供维护旧环境与开发实验，**不属于首期新用户安装流程**，其中旧 API Python 分轨链仍需要研究依赖。安装包不包含 `RecommendedModel.ps1`，不要从旧文档启动它。模型对照见[本地评估记录](local-model-evaluation.md)。未经用户明确要求，不修复、升级、下载或删除其模型。

## 开发者验证

源码构建使用 `src/Build.ps1`，无需模型。`src/Test.ps1 -NativeOnly` 在隔离 Windows 桌面测试速记、录音时间轴、MP3 完整解码和本机回环模拟 API；不操作用户剪贴板、录音设备或真实服务。Python 合同测试属于开发环境，不是用户依赖。真实录音、播放、切换设备或上传音频必须提前确认，测试输出独立保存。

更新或卸载前等待后台工作结束并让用户从托盘正常退出，不强杀进程。卸载保留笔记、配置、后装环境与模型。仍未完成的干净 Windows 或硬件验收写“未测”，不要借宿主依赖充当干净环境。
