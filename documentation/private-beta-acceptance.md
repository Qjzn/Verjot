## 维护者复现入口

下列两个工具只在源码仓库运行，不进入安装包；使用独立输出目录，不能传正式笔记目录：

```powershell
# 长音频检查：需已安装本地音频依赖和可信 MP3 编码器。
# 默认30/60/120分钟，总保留资料约4GB；输出目录必须不存在。
.\.venv\Scripts\python.exe -B tests\ValidateLongTimeline.py --output validation\long-timeline-new

# 仅在人类完成逐段确认后评分，身份映射只由开发集学习。
.\.venv\Scripts\python.exe -B tests\EvaluateSpeakers.py --review '<人工核验JSON>' --prediction '<候选时间线JSON>' --output '<新的评分JSON>'
```

评分工具拒绝未确认标注、越界区间、重叠的核验窗口及重复窗口编号，分别报告正确、错归属、未映射、缺失/未知、重叠和未确认参考时长；无预测不能算正确，留出集不重新学习映射。不完整标注不报告完整DER，人工片段得分不代表整场准确率。回归只使用合成身份和区间，真实姓名、正文、声纹及报告留在忽略的验证目录。

## 发布前剩余门槛

1. 在真实干净 Windows 客体完成从安装器到首次设置、速记、新下载依赖模型及CPU转写的完整过程，检查安装中断、升级与卸载保留资料；分别记录具体 Windows 版本。没有测试过的系统不标通过。
2. 补齐真实麦克风人声、设备热切换、人工回听，以及30/60/120分钟真实采集。检查时间戳估计的实际影响，不移除警告伪装达标；磁盘满与意外退出在隔离环境验证。
3. 完成人工核验，再独立比较短句处理、原始麦克风锚点及组合。仅在留出集本人错归属和总体混淆下降、同人拆分不增且未知覆盖未掩盖退步时，考虑替换候选；不固定人数，不强绑麦克风为本人。
4. 核对最终安装包哈希、明确文件清单、离线资料链接、第三方许可、历史新增内容和敏感信息；对应提交CI通过后再决定私有候选发布。名称与图形公开使用待确认项保留，仓库公开另行决定。

原会议、个人配置和正式默认不覆盖；不上传音频，不以未完成的人工验证或模拟结果解除上述门槛。
