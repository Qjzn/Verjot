## 发现并修正的上手断点

- Git 源码入口与 EXE 运行目录混用：源码先进入 `src/`；EXE 安装版直接在程序目录运行命令，不追加 `src`。
- 源码测试和运行程序混放：首页只展示产品资料，测试统一由 `src/Test.ps1` 找到 `tests/`。
- 打包阶段可能读到本机遗留文件：运行文件明确映射到 `src/`，不回退旧根目录副本；NAudio 改读 `src/lib/NAudio.dll`。
- 源码构建后缺离线指南：普通源码安装构建也复制当前指南与欢迎页；安装包 README 的配置链接按实际平铺目录转换。
- 安装版误用源码测试命令：自检与维护者回归分别说明；删除迁移后不能直接运行的根目录 unittest 示例，明确安装包不含测试和旧版整理工具。
- 离线资料存在 CI 相对链接断点：工作流链接改为 GitHub 地址，源码构建补齐指南引用的安全说明和第三方许可；分别检查源码运行目录与安装载荷的本地链接。
- 首次填写未创建的保存目录时无法继续：实际窗口会明确提示先创建且保留输入，补清目录选择器可新建文件夹；回归同时验证错误路径与修正后保存。测试读取缺依赖提示时增加就绪等待，避免对话框内容未生成的时序误报。
