# 涉及数据与副作用的流程

| 流程及前置条件 | 顺序、检查与结果 | 拒绝/失败行为 |
| --- | --- | --- |
| 当前用户首次启动；安装目录可写 | 没有 `config.json` → 原生设置 → 校验路径和快捷键 → 创建配置 → 托盘；不启动录音或下载。 | 取消不创建配置；并发出现配置不覆盖；冲突留在设置页。 |
| 当前用户输入速记 | 快捷键 → 原生编辑 → 用户主动粘贴时读取一次剪贴板 → 后台草稿和 Markdown/图片保存。 | 外部改写不覆盖；输入法组合或保存失败时阻止未保存退出。 |
| 当前用户开始/结束会议 | 检查运行环境 → WASAPI 双路无损分段 → 有效时长保护 → 本地 worker → MP3 与 Markdown → 成功后清理临时音轨。 | 不足保护时长不转写；采集异常保留告警；转写/发布失败保留恢复资料。 |
| 用户选择 API 模式 | worker 准备讲话片段 → 从指定环境变量读取密钥 → 提交配置的 `/audio/transcriptions` → 校验响应与断点保存。 | 拒绝含凭据/查询等危险 URL，拒绝转发重定向；错误不回显响应正文或密钥。远端应使用 HTTPS。 |
| 升级/卸载 | 安装器核对登记目录和占用状态 → 仅更新/移除安装器拥有的文件。 | 目录归属不符、活跃会话、未知状态或被占用文件会阻止操作；保留配置、环境与用户资料。 |

本机操作使用当前 Windows 账户权限，没有跨用户授予权限的接口。API 调用越过本机边界，服务商权限和数据保留由用户选择的服务决定；本地模式不会将转录音频提交该接口。
