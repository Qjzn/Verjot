# 涉及数据与副作用的流程

> beta.11 首期调整：新用户默认仅录音，无推荐本地模型下载；速记、原生 MP3 导出与可选第三方 API 均无需 Python 或模型。新 API 提交完整 MP3，身份信息仅来自供应方；已有 local 模式及下文历史 Python 流程保留兼容，不属于新用户推荐路径。新会议按 `Verlog年月日时分/同名.mp3` 保存，API 成功后生成同名 Markdown。实际配置见[安装说明](install-windows.md)。


| 流程及前置条件 | 顺序、检查与结果 | 拒绝/失败行为 |
| --- | --- | --- |
| 当前用户首次启动；安装目录可写 | 没有 `config.json` → 原生设置 → 校验路径和快捷键 → 创建配置 → 托盘；不启动录音或下载。 | 取消不创建配置；并发出现配置不覆盖；冲突留在设置页。 |
| 当前用户输入速记 | 快捷键 → 原生编辑 → 用户主动粘贴时读取一次剪贴板 → 后台草稿和 Markdown/图片保存。 | 外部改写不覆盖；输入法组合或保存失败时阻止未保存退出。 |
| 当前用户开始/结束会议 | 只检查采集及保存条件，不检查模型/API → WASAPI 双路无损分段 → 有效时长保护 → 原生后台导出并校验 MP3；默认到此结束，有转写需求时才检查 API 配置。 | 不足保护时长不保留成品；采集异常保留告警；导出/转写失败保留恢复资料；不因未配置模型拒绝录音。 |
| 用户选择 API 模式 | 新 API 校验整条 MP3 → 明确确认上传 → 从指定环境变量读取密钥 → 原生提交配置的 `/audio/transcriptions` → 校验响应与断点保存。 | 拒绝含凭据/查询等危险 URL，拒绝转发重定向；错误不回显响应正文或密钥。远端应使用 HTTPS。 |
| 升级/卸载 | 安装器核对登记目录和占用状态 → 仅更新/移除安装器拥有的文件。 | 目录归属不符、活跃会话、未知状态或被占用文件会阻止操作；保留配置、环境与用户资料。 |

本机操作使用当前 Windows 账户权限，没有跨用户授予权限的接口。API 调用越过本机边界，服务商权限和数据保留由用户选择的服务决定；本地模式不会将转录音频提交该接口。
