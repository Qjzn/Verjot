# 首次使用检查

面向 Verjot 0.11 的日常桌面入口。完整步骤和真实界面图见[安装与使用](install-windows.md)。不需要先安装模型或运行 Python doctor。

| 步骤 | 操作 | 成功证据 |
| --- | --- | --- |
| 安装 | 校验 SHA256，运行 x64 安装器 | 开始菜单能找到 Verjot，首次启动可确认保存目录 |
| 速记 | Ctrl+Alt+J，输入中文，收起再打开 | 原内容、格式与保存位置正确；不以截图代替实际输入手感 |
| 图片 | 用户主动复制图片后粘贴、重开 | 图片仍在，其他程序的正常粘贴不受干扰 |
| 最近标签 | 悬停可预览、点击选中；经过标签间隙保持预览，下一篇准备好后直接替换；「更多…」输入名称搜索 | 离开标签列恢复当前便签；点击切换前先保存输入，原文件不被替换 |
| 修改名称 | 点击速记顶部文件名，直接输入新名称，回车确认；Esc 或点击正文取消 | 改名期间暂不切换预览，先保存输入再更新标签与搜索；自动保留 `.md` 后缀，同名、不合法名称、外部改动或未处理草稿不会被覆盖 |
| 阅读缩放 | 正文内按住 Ctrl 滚动鼠标滚轮，预览与编辑使用相同显示比例 | 放大／缩小显示，Markdown 正文未被改写成带字号内容 |
| 导航 | 文档菜单关闭再开启自动收起，首次移出再移回正文 | 顶部与底部立即恢复，滚动位置不跳动 |
| 录音 | 经同意录 20 秒，用户说一句话并自行播放已知声音 | MP3 可回听麦克风与电脑声，实际保存路径正确 |
| 麦克风暂停 | 录音中 Alt+Space，再按恢复 | 仅本人收音暂停，电脑声持续 |
| 可选 API | 配置兼容服务，检查并保存，确认上传后转写 | 同目录生成 Markdown；错误时保留 MP3 与原因 |

改名只移动当前 Markdown，不改写其他便签正文；其他文件中指向旧文件名的手动链接需自行更新。

默认保护时间 5 秒，测试录音应超过该时间。不要为了验证而录制用户不知情的声音，不自动修改系统音量或设备，不读取正式笔记充当测试样本。

请记录 Windows／版本／设备、实际步骤、通过或失败、文件位置及未测项。干净机器、设备切换、长会议与模型准确率是独立验收，不能凭短录音或合成测试标记通过。当前已知覆盖见[发布验收](release-readiness.md)。

旧 `tingji.py doctor/verify` 等入口只供历史研究；不作为桌面仅录音和原生 API 的新用户前置条件。
