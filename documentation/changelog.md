# 版本说明

## 0.1.0-beta.11（私有候选，未公开发布）

- 首期聚焦速记和录音，移除推荐模型下载入口和安装选项；保留已有本地模型、配置和本地转写兼容路径。
- 新用户默认仅录音，保存子目录 verbit；每场使用 verbit年月日时分文件夹，MP3 / Markdown 同目录同名，同分钟重录自动加序号，旧文件不改。
- 可选第三方 API 原生调用 /audio/transcriptions，无需 Python、本地模型或说话人依赖。配置服务地址、模型 ID 和密钥环境变量；上传前确认，拒绝重定向；仅显示服务实际返回的身份标签。
- 新 API 仅录音完整校验 MP3 后清理本场临时音轨；转写成功校验后清理，采集异常、失败或文件变化保留恢复资料。重试复用完整结果，不覆盖用户笔记。
- 新接口、长会议上限和文字/身份质量取决于供应方；回环模拟测试不代表真实云服务、设备或干净 Windows 验收通过。


## 0.1.0-beta.10 · 私有候选

- 浮窗统一使用逻辑坐标和字体缩放，修复告警标题截断以及缩放后文字/图标重叠；录音、就绪、转写、结果、告警状态共用布局，跨屏时重新排版成品路径。
- 设置窗口适配屏幕工作区，小屏和高缩放下保持保存/取消可见，页面可以滚动，三个标签按可用宽度排列；离线说明与模型准备窗口也约束在工作区内。
- 速记的原生最小尺寸不再大于可用工作区，避免高缩放下窗口被最小尺寸限制推到屏幕外。
- 修复英文 Windows 重定向控制台下，本地自检因中文输出编码失败而误报的问题；成功和失败分支均有 cp1252 子进程回归，不修改系统或 CI 的默认编码。
- 合并以下本地候选修复：默认仅录音、按需准备转写、速记滚动条/显隐/跨屏/输入性能。模型仍为千问 1.7B，音频处理质量边界不变。
- 安装包、校验和与验收结果单独核对；私有候选不代表已经公开发布，也不把模拟 DPI 当作真实设备验收。

### 仅录音与速记悬停稳定性

- 默认仅录音：无需准备模型，结束后导出 MP3；设置中勾选“录音 + 转写”才展开模型准备与配置。每场开始时固定选择，手动转写仍可从最近会议发起，导出期间重启也保留该场选择。
- 仅录音不显示转写失败；浮窗显示录音实际保存位置。无损资料暂留以支持后续转写，成功校验录音和转录后按原规则清理。
- 修复长正文清空及重新输入短文后残留滚动条；按原生编辑器内容高度判断溢出。
- 悬停不再反复修改整窗裁切区域；导航背景局部缓冲，已展开的标签不因跨控件悬停重复布局。隐藏导航时正文扩展至上下边缘，仅保留正常内边距；显隐只布局一次，保留选区与有效滚动位置，窗口外形保持稳定。
- 保留千问 1.7B 与既有识别标准；说明 CPU 长会议耗时及身份核验限制，不把本轮交互修复作为模型质量提升。

### 速记跨屏布局与交互

- 修复恢复旧窗口尺寸及跨屏 DPI 切换后底栏高度偏小、按钮裁切的问题；顶部、格式栏与最小尺寸按当前 DPI 校准，窗口适配当前屏幕工作区。
- 按钮使用短促、可中断的颜色过渡；最近标签离开和进入同时接续当前状态，静止时停止动画计时器。
- 原生拖窗期间暂时收起独立标签窗，结束后按鼠标位置恢复，避免标签跟随拖动造成错位感；不动画缩放正文或修改 Windows 全局拖动设置。

### 设置与本地转写准备

- 修复设置页在状态不变时仍每秒重复重绘按钮的问题；页面切换仅在设置内容区合成绘制，转写方式与高级选项的显隐合并布局，减少闪烁，保留原生下拉框和键盘焦点。
- 设置统一为常规、转写、关于与更新三个页面，调整留白、按钮层级与清晰 Logo，适配 96/144 DPI；本地模式默认隐藏 API 表单，高级选项按需展开。
- 转写页用一个“启用本地转写”入口准备固定依赖、千问模型和说话人组件，显示当前步骤与文件下载进度；关闭设置可在后台继续。
- 准备完成须用内置合成中文样本实际运行说话人组件与 CPU 转写，验证后显示可用；不录音、不播放、不读取用户会议。文件或关键组件变化时就绪凭据失效，需要重新验证。
- 修复 Windows PowerShell 将模型正常写入 stderr 的进度误判为失败的问题，改按进程退出码判断；异常提示不再为空，诊断与普通输出分别保存。
- 缺少本地转写环境时先保留录音，提供“启用并转写这场”和“仅保留录音”；选择前者会在本次程序运行期间、准备完成后继续这场转写。改成 API 模式不会沿用本地同意上传，退出程序后未转写资料保留，可从最近会议继续。

### 模型准备反馈与浮窗入口

- 修复模型检查子进程提前退出、状态文件缺失或损坏时窗口仍停在“检查中”的问题；恢复重试按钮并明确提示，保留已下载资料。
- 采集告警会议的输出文件后来缺失时，浮窗、通知与最近会议显示“采集异常 · 文件需检查”，不再沿用“转写完成”。
- 推荐模型准备成功显示“已准备好”，按钮改为可选的“重新检查”；点击被阻止时保留具体原因，不再被旧成功状态覆盖。已导出 MP3、等待模型配置的会议不会阻止准备模型。
- 移除浮窗返回箭头。待机时显示速记、录制、设置三个图标；悬停说明使用当前配置的快捷键，设置不分配快捷键。待配置或异常状态保留简短原因和三个入口，转写时保留真实进度。
- 转写成功但录音存在采集异常时，明确显示“转写完成 · 录音需检查”，完整设备原因可悬停查看；继续保留恢复资料，不以重新转写掩盖漏录。

### 录音先导出与恢复

- 新录音结束后先合并并校验一条 MP3；原生编码不等待 Python、模型或转写环境，保持默认 192 kbps。
- 首次转写继续使用无损分轨，重试复用已校验 MP3；成功核对录音、Markdown 和完整结果后清理临时资料。失败或采集异常保留恢复资料并显示原因。
- 最近会议默认打开成品位置；恢复资料单独作为异常检查入口，旧录音不自动转换或清理。
- 修复部分设备扩展格式 WAV 无法导出及首次验收桥的参数调用错误。安装包包含 MP3 编码库及许可/对应源码。
- 实测暴露蓝牙时间戳回退与开头漏录。修复可复现的时间戳兜底顺序错误，并保留采样位置回退告警；后续短样本开头恢复，但集中复验仍有端点异常，不能宣称设备问题全部解决。
- 补齐带倒计时的隔离设备复验及逐包时间线报告；修正安装验收依赖旧标题和旧录音阻断预期的问题，真实沙箱中的首次设置与无 Python 速记已复测，完整本地依赖/模型安装仍单列。

### 速记交互与标签管理

- 最近纸贴与可搜索的「更多便签」支持右键删除、确认后回收；当前输入先保存，恢复草稿和外部修改受保护，图片附件保留。
- 纸贴始终位于正文外，贴左屏时移至右侧，无空间时从顶部文件名切换；预览保持编辑焦点，输入前退出预览，移回可恢复正在收起的标签。
- 图片四角等比缩放、边缘自由调整，尺寸随 Markdown 保存并支持撤销重开；双击或右键查看本地原图，也可恢复原图比例。
- 增加边缘、悬停焦点、图片、删除保护和输入响应的隔离回归；不使用系统剪贴板或全局输入注入。

## 0.1.0-beta.6 · 推荐模型下载候选

- 速记纸贴改为始终位于正文外，贴左屏时转到右侧；两侧无空间时从顶部文件名切换。「更多」升级为带文件名搜索、当前标记及键盘选择的紧凑列表。悬停预览不再隐藏原编辑控件或切换输入焦点，输入前先退出预览，快速移回也会恢复正在收起的标签。
- 图片四角保持当前比例、边缘可单独调整宽高，尺寸随 Markdown 保存；支持双击或右键查看安全的本地原图，并可恢复原始比例，原图不改写。
- 复审速记图片缩放：真实按键预处理下 Esc 先取消拖拽，再按才收起；滚动或改变编辑器缩放时取消旧拖拽；长截图按原图精确比例限制预览与提交尺寸，避免松手跳变或取整导致拒绝。
- 速记标签完整名称提示改为正文外安全定位，屏幕边缘无法放置时隐藏提示；拖动窗口也会关闭旧位置提示。顶部文件名与图标对齐；鼠标离开窗口后上下工具栏收起，仅保留正文，进出不重排正文；菜单和保存异常不被自动隐藏。
- 图片拖拽使用轻量轮廓预览，松开后整步应用；增加右键适合窗口、放大、缩小，尺寸随 Markdown 保存，撤销、重做与重开恢复；原图不改写。选区/文件切换、失去捕获或按 Esc 取消未提交缩放，并限制过大显示及极端长宽比导入。

- 速记支持独立新便签和恢复上次文件；顶部合并为新建、Logo 与文件名、置顶、最小化和关闭，取消重复标题。左侧纸贴标签按窗口高度显示，支持短过渡、完整名称提示、延迟只读预览及点击切换；不挤动正文，切换先保存，冲突不覆盖原文。预览上限与图片引用明确区分于完整编辑，可从文档菜单关闭。滚动条改为细滑块与宽点击区域，继续使用原生滚动与输入，不引入网页组件。

- 速记底部增加轻量格式工具栏：加粗、斜体、下划线、删除线、项目符号及图片选择。修正首版仅插入 Markdown 符号的问题，改为原生字体直接呈现；支持组合格式、后续输入样式、单次撤销、字体修改自动保存及重开恢复。仍保存 Markdown，不增加 RTF 附件，不在每次输入时全篇解析。
- 速记按钮悬停显示用途与快捷键；圆点列表回车自动续项，空项回车退出列表，Shift+Enter 仅换行。移除正常输入/保存时反复切换的状态行，保存位置收为右下角文档图标，可悬停查看完整路径或点击打开恢复菜单；底部七个图标随窗口宽度均匀排列，保存异常仍明确提示。
- 修复整行列表加粗、下划线等组合格式保存后，重开将圆点显示为短横线并影响续写的问题；补充七按钮提示实际出现/隐藏，以及带图格式列表保存、重开和续写回归。
- 修复右下角保存位置提示在按钮上沿闪烁：按多行内容高度定位，避免提示遮住悬停目标而反复进入/离开；增加原生窗口边界与持续显示检查。
- 原生录音不再被缺失 Python、模型或 API 密钥阻止。结束时才检查转写环境，未就绪明确显示「录音已保存 · 待配置转写」，保留无损分段并可配置后重试。
- 设置可在密钥尚未安装时保存，实际转写时检查；新录音第一次转写使用当前保存的模型与术语，已有部分转写及旧会议继续保留配置一致性保护。云端提交另行确认，不静默上传。
- 转写页显示本地模型文件就绪情况，区分「选择本地模式」与「下载并安装模型」；读取新配置的用户密钥变量无需重启托盘。

- 暂停快捷键（默认 Alt+Space）改为仅暂停/继续麦克风，电脑声音与会议计时持续；与浮窗麦克风按钮共用状态，右键菜单合并为一个带快捷键的麦克风操作。已有 `pause_hotkey` 自定义组合沿用；旧整场暂停资料不改写。
- 安装可选下载千问中文转写，默认不勾选；设置的转写页增加「下载推荐模型…」。不向普通用户展示多个研究模型。
- 独立原生下载窗口显示步骤、模型文件进度、失败重试与日志入口；关闭窗口后后台继续，再打开可查看状态。
- 缺少 Python 时下载并校验应用私有 CPython，不修改系统 PATH、注册表或文件关联；已有环境保留，兼容的 CUDA 12.8 环境沿用，不强制改成 CPU。
- 复用既有安装及断点下载，准备环境不构建正在运行的 EXE，不创建或修改个人配置、快捷键及自启。准备期间速记和原生录音仍可使用，转写启动和环境修改互斥。
- 推荐 ASR 固定已验证的权重 revision，说话人文件增加固定 SHA256；不自动追随上游 latest。
- 修正设置从 150% 屏幕打开到 100% 屏幕时部分控件被裁切的问题，常规内容可滚动，底部操作列随窗口宽度变化。

模型与依赖准备成功不等于设备、转写效果或说话人质量验收通过。本候选仍未实现缺少转写引擎时直接录制并导出 MP3 的独立录音流程。

## 0.1.0-beta.4 · 候选版

本地默认仍为 Qwen3-ASR-1.7B。此版本没有升级模型，也没有宣称说话人识别质量已达标。干净 Windows、真实长录音与身份质量仍按私有测试验收表分别记录。

提供 EXE 安装包、首次设置、全局速记、双路会议记录及本地/API 转写的基础流程。
