# 版本说明

## 0.1.0-beta.5 · 审查修复候选

- 修复缺少 API 密钥时无法启动桌面或进入设置切回本地模式的问题；开始录音前仍严格检查密钥，首次设置选择 API 时仍需有效配置。
- 修复更新检查向正式版推荐测试版的问题，同时检查版本标签与 GitHub 的预发布标记。
- 版本与安装说明改用内置只读窗口，不依赖 Markdown 文件关联或外部阅读器。
- 设置保存先合并所有本次编辑再校验，避免旧 API 配置阻止用户切回本地。
- 补充设置控件内部布局与原有默认开始菜单入口保护检查。

## 0.1.0-beta.4 · 候选版

- 设置增加“转写”页：选择本地/API、填写 API 地址和模型 ID、密钥环境变量名、超时、术语提示、上下文、轻量降噪及回声去重。
- 常规设置可启用或关闭登录 Windows 后自启；默认不主动开启。
- 增加“关于与更新”：程序版本、MIT 许可、GitHub 项目与发布入口、本机版本说明、手动检查及可关闭的自动检查。
- EXE 安装固定创建当前用户开始菜单入口。点击开始菜单或桌面快捷方式时唤出浮窗；已有进程继续使用，不启动第二份录音。
- 构建时嵌入实际版本，安装包与程序显示一致。

更新检查默认关闭，不发送音频、笔记、保存路径或 API 密钥。仅查询版本，不自动下载安装；升级前需正常退出。私有仓库无法匿名查询时显示访问说明，用户在自己的浏览器登录下载，不把 GitHub 凭据交给程序。

本地默认仍为 Qwen3-ASR-1.7B。此版本没有升级模型，也没有宣称说话人识别质量已达标。干净 Windows、真实长录音与身份质量仍按私有测试验收表分别记录。

## 0.1.0-beta.3 · 本机验证候选

补充首次设置、离线速记、新用户安装验证与中断恢复检查。未替代干净 Windows 实测。

## 0.1.0-beta.2

提供 EXE 安装包、首次设置、全局速记、双路会议记录及本地/API 转写的基础流程。
