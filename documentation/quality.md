# 录音与转录质量标准

本文区分工程正确性、重复稳定性和内容准确性。用户已明确要求**跨两轨同一人统一编号、不同人分开**，这项需求不再待确认；下列数值门槛仍是待确认的验收提案，尚未获得逐项认可，也没有全部完成测试。当前不能宣称「稳定且高质量录音/转录已达标」，转录中的说话人限制说明暂时保留。

## 指标如何计算

| 维度 | 指标与方法 | 能回答的问题 |
| --- | --- | --- |
| 双路录音与合并 | 比较有已知时间位置的麦克风、电脑声音与输出 WAV；测事件偏移、整场长度误差、静音区间和样本差异。分别检查原轨削波与混音新增削波。 | 两路是否进入成品，是否遗漏、偏移或因混音而失真。 |
| 运行稳定 | 在同一固定版本与配置下重复执行明确的操作场景，记录成功次数、丢音、异常和产物一致性。不同机器、设备和配置分别列结果。 | 已覆盖的场景是否可重复完成；不能外推所有设备与长会议。 |
| 中文准确性 | 人工听写、复核后形成真值。字错误率 CER =（替换字数 + 删除字数 + 插入字数）/ 真值字数；统一忽略标点、空格，事先固定英文大小写与数字规范。 | 中文正文的实际错漏程度。数字、日期和金额另作严格核对，不能借规范化掩盖错误。 |
| 关键实体 | 在人工真值中标注姓名、产品名、日期、金额、数量等，按完全匹配统计正确实体数 / 实体总数，同时列出错误原文。 | 决策相关词与数字是否可靠，而非只看平均 CER。 |
| 说话人归属 | 人工标注每段真实说话人和起止时间，经匿名编号最佳匹配后统计错分、漏检和误检；用 DER =（漏检时长 + 误检时长 + 错分时长）/ 真值说话时长。 | 编号是否对应真实说话人。跨轨同一人、串音和重叠讲话须单独评估。 |
| 时间戳 | 对齐人工标记的句段起止点，统计绝对偏差的中位数和第 95 百分位；重点标记与暂停按同一会议时间轴核对。 | 用时间戳回听时能否找到对应内容。 |
| 文本完整性 | 逐项检查重复句、静音幻觉、漏段、错误拼接和未完成文字；核对重试与改名后的用户笔记保护。 | 成品是否便于阅读和继续编辑，是否改坏已有内容。 |

CER 与 DER 应分别报告总体值和每个场景的值，不能用平均数掩盖某个常见场景的失败。重复输出相同不代表该输出正确；音轨已合成一条，也不代表两轨上的同一人已正确统一编号。当前策略直接对两路讲话片段的声纹进行全局完整链接联合聚类，要求组内片段彼此相符，不对局部簇作不可拆分的硬合并；身份区分不足、短段与重叠保留「待确认」。验收须同时报告误并、漏并及待确认时长，不能靠全部标为待确认取得虚高准确率。

识别片段默认使用可关闭的轻量低频处理：`asr_denoise: "light"` 执行零相位 70 Hz 高通，`"off"` 关闭，保留 WAV 不变。降噪对比须固定原音频、模型和人工真值，分别计算 CER 与关键实体错误；当前不宣称该处理对所有声音有效或有广泛准确率改善。

## 高质量目标提案：待确认

| 项目 | 初步目标 | 验收边界 |
| --- | --- | --- |
| 录音完整 | 授权操作矩阵中所有测试产物可回放，两路应有的声音均存在，无非预期丢音或文件损坏。 | 包括麦克风开关、整场暂停、仅电脑声、仅麦克风和交替/同时讲话；不把设备原本没输入的声音算成已录下。 |
| 合并时间轴 | 已知事件对齐偏差 ≤20 ms，整场长度误差 ≤100 ms；暂停区间与墙钟一致，混音无新增削波。 | 合成精度与真实设备录音分别验收；本来已失真的输入不能靠混音保证修复。 |
| 中文正文 | 清晰普通话 CER ≤3%；常见线上会议场景 CER ≤5%。 | 方言、远场、强噪声和重叠另列，不在未测试前承诺同一阈值。 |
| 关键实体 | 明确可听的关键实体正确率 ≥99%；任何错误均保留明细并人工复核。 | 包含数字、金额、日期、姓名和项目/产品名；不自动从语境猜测替换。 |
| 说话人 | 需求为同人跨轨统一、不同人分开；建议非重叠讲话 DER ≤10%，跨轨同人和串音的归并须有人工真值独立报告。 | 数值门槛待确认。重叠讲话与待确认时长单列，不以四个人分出四个编号认定归属正确。 |
| 时间戳 | 人工边界偏差中位数 ≤0.5 秒，95% ≤1 秒。 | 测量边界与容许区间预先固定；不能靠放宽统计口径通过。 |
| 重复与长会议 | 同输入至少 5 次结果可重复；实际设备操作矩阵每项至少 3 次；另做至少 3 场 ≥30 分钟的双路会议验收。 | 需要真实输入和人工真值，记录环境与失败，不仅运行模拟夹具。 |

确认标准时还需明确：主要会议语言与口音、典型人数、耳机或扬声器、常见术语、可接受的人工校对量，以及跨轨误并、漏并和待确认时长的容忍范围。高质量目标一旦确认，应固定样本与统计口径，再决定何时删除限制说明；不因一次满意结果而取消边界。

## 当前已有证据及其限制

| 已执行测试 | 客观结果 | 不能据此声称 |
| --- | --- | --- |
| 合成双路合并重复测试 | 30 次：时间轴误差 0 ms，样本误差不超过 1 个 PCM 量化单位，无削波。 | 真实麦克风/播放设备没有时钟差、丢帧或串音，也不能证明中文识别正确。 |
| 官方四人样本重复分组 | 同一输入 5 轮均得到 4 簇、10 段。 | 没有人工真值核对，不能计算归属正确率/DER，不能证明真实双路中文会议已稳定高质量。 |
| 全局声纹：同源复制双轨 | 5 轮输出一致；20/20 个参考讲话片段可归属。同一原样本的局部分组参考关系：同人 26/26、异人 74/74。 | 复制同一声音是受控场景；这些是参考关系核对数，不是人工真实身份准确率。 |
| 全局声纹：不同语句分到两轨 | 5 轮输出一致；10/10 个参考讲话片段可归属，参考同人关系 6/6、异人关系 18/18。 | 不代表跨设备真实会议的全部声道、噪声与讲话变化都已覆盖。 |
| 全局声纹：15 dB 声道差异 | 5 轮输出一致；17/20 个参考讲话片段可归属，已归属部分的参考同人关系 20/20、异人关系 50/50；3 个参考片段需核对；2 个重叠 segment 标为未知。 | 未确认片段仍需核对，不能隐藏后只报已归属部分的准确率；参考来自同一原样本及其变换，不能据此报告人工身份准确率或 DER。 |
| 中文小样本降噪对照 | 官方 19 字、约 5.55 秒样本，原声/加 20 Hz 干扰分别配 `light`/`off`，共 4 项 CER 均为 0；每项帧数保持 88,747。 | 仅证明该小样本没有退化；没有证明更广泛中文会议的 CER 改善。 |
| 滤波信号检查 | 20 Hz 衰减 43.59 dB；300 Hz 幅度保留 99.706%；48,000 帧长度不变，脉冲峰位置无偏移。 | 信号指标不能代替对不同人声、设备和噪声的识别内容验收，也不是全频降噪效果。 |
| 本机真实菜单、快捷键与短录音 | 分别从浮窗右键、默认全局快捷键完成开始、标记、整场暂停/恢复及结束，浮窗麦克风开关同时核对；两场约 13.15 / 12.84 秒均完成本地转写，WAV 长度误差均小于 0.01 ms，暂停内部为静音，无满幅样本。 | 首轮麦克风接近静音，第二轮两路检测到信号；未经人工听写和身份标注，不能证明跨设备身份归并准确，两轮短录音不能替代长会议验收。 |
| 本机实际会后命名 | 从浮窗菜单打开命名框、输入并保存，实际结果路径更新；MD 和 WAV 哈希前后相同，三处管理路径一致。完成场次重试返回 0，未运行模型或子进程。 | 只使用本次测试会议，未批量重命名或修改用户历史笔记。 |
| 原生界面与跨屏显示 | 356 条原生断言通过，另有 2 项符号链接权限相关检查跳过；实测 150%→100%→150% 时浮窗为 279×102→186×68→279×102，命名框和菜单无裁切。 | 界面、配置和状态正确不能证明说话人身份或转录正文准确，也不能覆盖所有显示器和设备。 |
| 手动清理后的历史状态 | 修复后 412 条原生断言通过，2 项符号链接权限检查跳过；实际运行菜单核对 3 条仅保留转录的记录和 5 条两份成品均已移除的旧记录，分别保留转录入口和隐藏历史；旧版音频文件名解析继续执行路径检查。 | 依据正常完成状态和当前文件是否存在分类，不能区分人为删除与其他软件移除文件；不恢复或重建已删除成品。 |

新全局聚类的三个受控场景合计 5 轮 × 3 场景 = 15 次，重复结果一致。参考身份来自原样本的局部分组和受控变换，不是人工逐段真实身份标注；这些结果支持已覆盖条件下的重复稳定性，不能宣称全面达到质量目标。

以上是开发过程的定向证据，不是用户质量验收。模型版本、依赖、设备或分段策略变化后，需要复测相关项目。测试记录应包含样本来源、授权、版本、设置、指标、错误明细和实际退出码；私密会议原音频、转录、设备个人信息及本机绝对路径不进入 Git 仓库。
