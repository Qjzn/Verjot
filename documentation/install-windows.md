# Windows 安装与快速上手

## 系统条件

Windows 10 1809+ / Windows 11 x64，.NET Framework 4.8，正常可用的音频设备和可写保存目录。**速记、录音和新 API 转写均不需要 Python、模型、FFmpeg、Visual Studio 或开发环境。**

`0.1.0-beta.14` 是私有候选，尚未公开发布。旧 Release 可能仍包含本地模型推荐流程，应使用与本说明匹配的候选包。仓库保持私有；安装包尚未签名，下载后核对随包 SHA256。

## 安装和首次使用

1. 运行 `verbit-0.1.0-beta.14-setup-x64.exe`，按当前用户安装，无需管理员权限。默认位置 `%LOCALAPPDATA%\Programs\verbit`。
2. 安装只提供桌面快捷方式、开机启动等选项，**没有模型下载选项，不后台下载模型**。
3. 首次打开选择已存在的保存目录，确认四组快捷键，保存并启动。默认仅录音，不要求 API 或模型；取消不创建配置，下次可重试。
4. 开始菜单 **verbit → verbit** 或桌面/托盘可打开浮窗。`Ctrl+Alt+J` 打开置顶速记，输入文字、粘贴图片并自动保存。
5. `Ctrl+Alt+L` 开始/结束录音；`Alt+Space` 只暂停/恢复麦克风，电脑声持续录制。浮窗红色方块结束，右上角关闭仅隐藏。

默认 5 秒误触保护：不足 5 秒不保存、不转写；设置中可修改。设备选择为空时跟随默认麦克风，电脑声默认收录活动输出；驱动、独占或受保护音频仍可能不可采集，请实际回听。

## 文件位置与命名

新安装的会议子目录为 `verbit`；已有用户的目录配置不变。每场新会议使用独立文件夹：

```text
<保存目录>/verbit/verbit202610271430/
  verbit202610271430.mp3
  verbit202610271430.md    # 仅在转写成功后出现
```

名称是 `verbit` 加录音开始时的本地年月日时分（12 位）。同一分钟重录使用 `-02`、`-03` 等序号。更改保存目录只影响后续录音，不迁移、改名或删除旧文件。最近会议提供定位录音、回听和定位转录。

录制中无损分段位于程序 `work/<内部会议编号>/`，不是日常成品。新 API 模式仅录音也会在 MP3 完整解码、时间轴和哈希校验后清理本场临时音轨；之后仍可从 MP3 转写。开启自动转写时，转写失败保留临时资料；成功校验后清理。采集异常或清理失败时保留资料并提示。已有本地模式继续保留无损轨，按原流程转写。不要在录制或恢复中手动清空 work。

## 启用会议转写

首期不推荐、不下载本地模型，默认只录音。可在「设置 → 转写」主动勾选 **录音 + 转写**，选择 **自定义第三方 API**：

| 字段 | 怎么填写 |
| --- | --- |
| API 地址 | 服务完整前缀，如 `https://provider.example/v1`；程序追加 `/audio/transcriptions`，不会自动猜 `/v1`。使用你信任的 HTTPS 服务。 |
| API 模型 ID | 供应方支持的音频转写模型完整 ID，可自定义；普通聊天、Omni 的模型名不代表兼容此接口。 |
| 密钥变量名 | 默认为 `TINGJI_API_KEY`，这里只填变量名。 |
| 超时 | 10–600 秒，默认 120；长会议需根据服务调整。 |

在 Windows 搜索“编辑账户的环境变量”，新建用户变量 `TINGJI_API_KEY`，值填自己的 API Key；不要粘到配置文件、聊天或截图。保存设置后生效，密钥会重新读取，无需为新用户环境变量重启托盘。设置保存不会试传录音或检查余额。

未启用自动转写时可留空 API 字段；填写时地址与模型需成对有效。录音始终不依赖 API Key。开始转写前才检查密钥，并显示服务地址与模型，询问是否上传；取消后仅保留录音。

新 API 流程原生流式上传一条已校验 MP3，不安装本地说话人模型。期望 JSON 至少含非空 `text`，或含 `start`、`end`、`text` 的 `segments`；服务如返回 `speaker` / `speaker_id` 则原样显示分组。没有身份信息时只显示文字，**不自动识别人名或宣称全局声纹一致**。使用标准 `response_format=json`；仅支持 WebSocket、URL 异步任务或聊天音频输入的服务需要专门适配，不能直接填写。

第三方的文件大小、时长、语言、收费、数据保留和准确率由服务商决定。一次提交整条 MP3，不自动切块以免打断供应方全局说话人上下文；超出其上限会提示 HTTP 错误并保留文件。超时或断网时服务可能已接收并计费，工具不自动重传；人工重试前先确认。拒绝 HTTP 重定向，错误信息不保存服务响应正文或 Key。

可从最近会议手动转写。成功结果先保存到本机恢复检查点，再创建同名 Markdown；重试复用同一配置的完整结果。已有笔记不同、输出被改或配置与已确认任务不一致时拒绝覆盖。切回仅录音不删除 API 设置；已有本地模型与配置也保留，但设置和安装器不再提供下载入口。

## 更新、卸载和失败恢复

更新前结束会议、等转写完成、保存速记并从托盘退出。安装到原目录；保留配置、已有模型、Python 环境和旧录音。安装安全检查不会强制结束进程，不要删锁文件绕过。首次设置不会覆盖已有配置。

卸载只删除安装器管理的程序和快捷方式，保留配置、用户笔记、录音、后装环境、模型与恢复资料。因此目录仍有文件不代表卸载失败；不要把用户保存目录当缓存清理。

转写失败先看最近会议具体原因，再检查地址、模型、用户密钥变量、网络、服务商限制和磁盘权限。录音文件被修改时不会覆盖。采集异常需回听，不能仅凭 MP3 可解码认定声音完整。干净 Windows 全流程、真实设备和长会议覆盖见[验收记录](release-readiness.md)，模拟服务测试不代表你的供应方已验证。

开发者构建与已有本地实验环境见[AI 安装说明](ai-install.md)；配置字段见[配置说明](configuration.md)。

## 精简右键菜单

托盘和录音浮窗共用常用菜单。录音中才显示麦克风暂停/继续、重点标记；显示/收起浮窗合并为一项。最近会议最多 6 场，更多历史从“打开会议记录文件夹”查看；失败记录保留重试和恢复资料入口。版本号、更新与配置说明从“设置”进入。速记图片可直接查看原图、适合窗口，其他缩放在“调整图片大小”内。

菜单字号与间距随 Windows 显示缩放自动调整，无需单独设置。
