# 安装与使用 verbit

适用于 **0.1.0-beta.38**。新用户只安装 EXE，不需要 Python、模型、FFmpeg、CUDA 或 Obsidian。

## 1. 下载与安装

需要 Windows 10 1809+／Windows 11 x64、.NET Framework 4.8、可写保存目录和可用音频设备。安装包约 6 MB；基础包不含模型，录音临时文件另占磁盘空间。当前安装器未签名，企业策略可能阻止运行，请核对来源，不要关闭全局安全保护。

从 [beta.38 版本页](https://github.com/Qjzn/verbit/releases/tag/v0.1.0-beta.38) 下载安装包及 `SHA256SUMS.txt`。仓库私有时需登录有权限的 GitHub 账号。对下载文件运行：

```powershell
Get-FileHash -LiteralPath .\verbit-0.1.0-beta.38-setup-x64.exe -Algorithm SHA256
```

输出应与同版本 `SHA256SUMS.txt` 完全一致。不一致不要安装，重新下载核对。运行安装器，选择可写程序目录；开始菜单搜索 `verbit` 启动。已有安装请更新到原目录。

升级不会自动删除以前安装的模型和 `.venv`，所以旧用户程序目录仍可能占用数 GB；这不是基础安装包的体积。确认不再使用旧研究环境前不要自行清理，尤其不要把笔记、录音或 `work/` 当缓存删除。

## 2. 首次设置

首次启动确认保存位置、会议与速记子目录。默认仅录音，API 留空即可保存。快捷键字段点击后按组合键，Esc 取消；保存后生效。开机启动和后台更新检查均可按需开启，默认关闭。

![当前常规设置](../assets/screenshots/settings.png)

本图为演示设置，`C:\verbit-notes` 只是示例，请选择自己的文件夹。修改保存位置只影响后续新内容，不自动移动旧文件。

## 3. 写第一张便签

按 `Ctrl+Alt+J`，输入中文。停顿后自动保存；收起再打开恢复上次文件。左上角＋新建，点文件名查看最近便签。底部按钮可调整常用格式、插入图片；也可主动粘贴截图或拖入本地图片。

![当前原生速记](../assets/screenshots/quick-note.png)

默认置顶，置顶图标可切换。右下角文档菜单能打开保存文件夹，并切换「鼠标移出自动收起导航栏」。关闭后顶部与底部常显；开启后移出收起、移回正文恢复。便签正文保存为 Markdown，图片在 `速记/图片/`，请一并保留。

## 4. 录制会议

先取得参会者同意，再按 `Ctrl+Alt+L` 开始。跟随默认麦克风并捕获活动播放设备；`Alt+Space` 仅暂停／恢复麦克风，电脑声和计时继续。`Ctrl+Alt+K` 标记重点。

![当前录音浮窗](../assets/screenshots/recording.png)

再次按 `Ctrl+Alt+L` 或点结束按钮。等待导出与校验完成，从通知或托盘「最近会议」定位 MP3。默认不足 5 秒的误触录音不保留，可在设置修改。

默认文件为 `<保存目录>/verbit/verbit年月日时分/同名.mp3`，同分钟加序号。默认 192 kbps，约 86 MB／小时；分段临时轨需要额外空间。校验完成才清理本场临时音轨，异常时保留恢复资料。`work/` 不是日常成品目录，不要在录制或处理期间手动删除。

## 可选配置 API 转写

没有 API 也能录音。要自动生成文字，在「设置 → 转写」选择「录音＋转写」：

![当前可选 API 设置](../assets/screenshots/settings-api.png)

| 字段 | 填写方法 |
| --- | --- |
| API 地址 | 服务前缀，例如 `https://your-service.example/v1`，程序使用其 `/audio/transcriptions` 端点；不是聊天网页地址。 |
| 模型名称 | 服务商提供的完整音频转写模型 ID，不是任意聊天／Omni 模型。 |
| 密钥来源 | Windows 用户环境变量的名称，例如 `TINGJI_API_KEY`；不是密钥本身。 |

在 Windows 搜索“编辑账户的环境变量”，在**用户变量**中新增该变量并填写服务商 Key；不要把 Key 放进截图、聊天、配置示例或提交记录。回设置检查配置并保存，程序实际转写时会重新读取用户变量，无需重启托盘。检查配置和保存设置均不发送音频。

接口须接受 multipart `POST /audio/transcriptions`，支持 MP3、`model`、`response_format=json`，返回非空 `text` 或带 `start/end/text` 的 `segments`。服务如返回 speaker/speaker_id 才显示相应分组，不推断人名。不支持直接填写 WebSocket、URL 异步任务或聊天接口。

开始转写前显示地址与模型并确认上传；取消后保留录音。也可从最近会议手动转写。超时或失败不会自动循环重传，可能已产生费用；重试前查服务商记录。API 上限、速度、准确率、隐私政策须自己确认。连接本机 API 时，服务由你自行部署，程序不会自动探测旧模型。

## 更新、卸载与故障

- **更新**：设置 → 关于与更新 → 检查并更新。后台检查不等于自动下载安装。私有测试可在更新窗口勾选「使用已登录的 GitHub CLI」（先在本机安装 gh 并登录），或按[配置说明](configuration.md#窗口内更新)设置 `VERBIT_GITHUB_TOKEN`；不要把令牌发到聊天或配置文件。也可登录 GitHub 手动下载。升级前保存便签、结束录音和转写，使用程序正常退出，再安装到原目录。不要强杀或删除锁文件绕过检查。
- **卸载**：卸载器删除程序与快捷方式，保留配置、笔记、录音和恢复资料。残留用户文件不是卸载失败。
- **快捷键无反应**：从托盘打开，检查是否与其他程序冲突，再在设置中录入新组合。
- **录音没有声音**：确认实际有声音播放、Windows 默认麦克风正确，检查系统权限与设备；波形或可解码不能证明全部声音收齐，先做短录音回听。
- **转写失败**：最近会议查看具体原因，核对地址、模型、密钥变量、网络与服务上限；保留原 MP3 和恢复资料，不自动换服务或上传其他地址。
- **便签保存冲突**：不要覆盖外部修改，按提示保留草稿并检查磁盘文件。

本轮没有新增真实采集或外部 API 验证；干净 Windows 实测已按要求跳过。更详细边界见[发布验收](release-readiness.md)与[配置说明](configuration.md)。
