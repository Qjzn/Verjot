# verbit 界面与交互规范

本轮方向由用户确认的统一视觉稿确定，面向 Windows 原生桌面使用。保留现有 Logo、原生 RichEdit、文件格式和快捷键，不引入浏览器或界面框架。

## 视觉角色

普通表面使用白色，正文深色，辅助文字低一级，青蓝用于选中与操作；红色用于录制与结束。颜色集中于 `VerbitUi`，菜单保留 Windows 高对比语义。正文、表单与菜单按各自阅读密度使用角色字号，不把控件整体放大。

设置页保留三个等宽页签，尺寸按当前工作区收敛，内容可以滚动但保存/取消始终可达。仅录音不显示 API 表单；转写字段之外的高级选项折叠。不把单一选项做成下拉框，不显示无法生效的禁用处理控件。按键捕获沿用点击后按组合键，Esc 取消。

## 操作约束

- 浮窗始终只有一个；展开为 186×68 逻辑像素，收起为 Logo，Logo 点击开合，鼠标移入移出不改变形态。名称和 Logo 整组居中，不再提供独立收起按钮。展开后的右上角保留 X，仅隐藏浮窗，不退出程序、不停止录音或转写，可从托盘重新显示。
- 开合围绕可见 Logo 的屏幕位置进行，内容截图与 Logo 使用同一原点，文字不缩放、不从另一侧滑过 Logo。连续开合及中途反向保留当前位置和速度，不重新从起点播放。静止与动画始终保留同一个原生 Logo 控件和图标帧；窗口尺寸、圆角和内容可见性更新后统一呈现，避免切换绘制器导致空白帧。尺寸与圆角使用基于真实时间的临界阻尼弹簧，无回弹，中途反向保留速度；收起比展开稍快，静止后停表。
- 靠近屏边且展开空间不足时，先按工作区做必要的平滑避让；收起保留避让后的可见 Logo 位置。贴边条属于独立受约束形态，沿所在屏边向内展开；不以固定 Logo 原点为由把按钮推到屏外。
- 非按钮区域可拖动，按钮点击不意外拖动；置顶、屏边和混合 DPI 使用原生窗口逻辑。红色方块结束整场录音，麦克风开关不暂停电脑声。
- 速记导航栏隐藏只裁切界面，不改变正文尺寸、选区、光标、滚动位置或图片坐标。标题、图片和格式处理继续使用原生编辑路径。
- 标签悬停预览与点击固定分离；文件名提示沿标签所在侧向外贴近约 6 逻辑像素，按剩余屏边空间换行。没有安全空间时不跨越正文或远跳到头尾；完整名称也可在更多便签搜索。更多便签沿用菜单字号、颜色与紧凑行高，圆角搜索边框和选中背景，3 像素细滑块、10 像素操作区域，不常驻原生滚动槽，保留原生列表的滚轮、键盘和右键删除。静止无新增计时器。
- 右键菜单共用 renderer 与字号，快捷键右对齐，危险色只用于对应删除操作；保留系统菜单键盘导航。
- 常驻界面不堆叠说明小字。失败原因、恢复资料和重试保持可达，录音按钮始终代表开始录音。
- 更多便签由内部内容决定窗口宽度（220–280 逻辑像素），宿主不额外保留命令/箭头空区，右侧只留轻量滚动条和一致内边距。
- 浮窗操作行底部保留至少 8 逻辑像素，按钮统一为 28 逻辑像素。录音完成、转写完成/失败使用独立的 320×64 逻辑像素提示，显示三秒后自动关闭，不抢占输入焦点、不展开浮窗、不覆盖正在录音的控件；成功点击定位对应文件，转写失败点击重试该场会议。长路径保留文件名，完整路径可悬停查看。提示不由状态轮询触发，闲置时停表；最近会议提供持续可达入口。

## 流畅度与真实性

交互动画只负责短暂反馈，静止后停表。输入与拖动直接处理，不加缓动追赶。格式工具栏按 DPI 缓存字形字体，销毁时释放；不在绘制中反复分配字体。不得为录音、格式或图片测试读取或写入用户系统剪贴板，使用局部合成 DataObject。

配置检查只验证本机字段与密钥变量状态，不联网、不上传音频、不写配置。检查有效与服务连通、真实转写成功是不同证据。

验收包含隔离的原生输入、图片、格式、导航栏裁切、快速开合、拖动、屏边及 DPI 回归，并检查实际入口截图。事件耗时与队列延迟不能称为屏幕 FPS；合成测试不冒充真实中文输入法手感、真实录音或所有显示器已实测。

设置窗口按 DPI 缓存字体，在所有原生子窗口销毁后再释放；不能在跨屏布局中立即释放仍可能被原生绘制消息引用的上一屏字体。浮窗快捷按钮在鼠标移出后保留中间帧，完成淡出后停止定时器，不能仅更改动画数值却立即抹掉背景。

## 最近便签局部绘制验收

`0.1.0-beta.34` 修复选中行调用共享背景函数时擦掉其他文字的问题：只填充传入矩形，不再清空整个绘图表面；不增加整页刷新、轮询计时器或运行依赖。文件、列表数量和保存逻辑均未改动。

2026-10-29 本机记录：修复前新增的局部绘制断言失败，修复后菜单 569 项断言通过。六档合成缩放逐像素检查其他行不变；实际 96/144 DPI 双屏直接复制当前列表像素，覆盖逐行悬停、键盘选择、行滚动、滚轮、细滚动条拖动、搜索匹配/无匹配/清空、关闭重开及销毁后重新创建。

其他背景函数调用位于速记标题/格式按钮和浮窗操作按钮；设置页签已经按单项矩形填充。相关回归通过：浮窗布局与提示 664 项、设置 735 项、速记编辑 730 项、浮窗开合 2,965 项、回车续写 266 项，以及图片保存和输入响应检查。UI 队列 p95 18.96 ms、输入与原生更新 p95 5.03 ms、位置调用最大 15.01 ms；这些是调用耗时，不能作为屏幕帧率。

隔离测试不访问系统剪贴板、用户笔记或录音。六档合成坐标不等于六种物理屏幕；实际中文输入法手感仍需用户核对。真实回收站删除、真实采集、云端转写和干净 Windows 首装不属于本轮通过项目。升级核对正常保存退出、全部载荷、配置与模型/恢复目录，并比较原笔记和录音文件元数据。

## 原生组件状态（beta.35）

Cult UI 适用于 React 渲染层；本产品使用 C# WinForms 与 RichEdit，因此只参考其技能中的组件复用、反馈状态和键盘可达性原则，未移植或安装任何 Cult UI 组件。现有颜色、图标和布局继续作为视觉依据。

便签标题与格式按钮共用已有的短暂悬停反馈，并补齐鼠标及空格按下状态。按下仅改变背景，图标与点击区域不移动；拖出、释放、捕获丢失、键盘失焦、禁用或隐藏会清理对应状态。禁用不显示活动背景，高对比模式沿用系统前景和选中色。浮窗的关闭按钮复用同一实现，其余录音按钮沿用已有状态组件。隐藏立即停表，静止后停表，不以持续轮询或全局重绘实现反馈。

更多便签搜索框内提供 24 逻辑像素的清空按钮，有查询时出现；文本区域始终预留位置，避免显隐时文字横跳。点击清空恢复全部文件并把焦点交还原生文本框，不改变正文、文件或剪贴板。搜索显示匹配数/总数，没有文件与没有匹配结果使用不同提示。

标签列首次显示时，在原生窗口完成屏幕 DPI 初始化后重新应用行高、宽度和位置，再开始展开。文件列表未变化时也校准行高，避免 150% 主屏创建、100% 副屏显示造成重复缩放与边框间隙；不重置正文尺寸、选区或滚动位置，不新增轮询或全页刷新。
